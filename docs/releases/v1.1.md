# v1.1 (2026-09-14)

**Status:** Stage validation complete

**Audience:** Engineering release review

## Summary

v1.1 makes structured plan details authoritative for supported quote facts, adds full-catalog
comparisons and quote-input guidance, and preserves supported answers when another requested fact
is unavailable.

Stage evaluation results for the current release corpus cover all 143 turns without operational failures.
Review found 115 supported and useful answers, 26 useful answers with limitations, and two
Safe misses.

## What changed

- Made structured details authoritative for premiums, deductibles, out-of-pocket maximums, supported
  care costs, optional-package rates, and generic drug-tier cost sharing.
- Added definitions and evidence boundaries; removed the upstream `covered` flag because it did
  not establish a shopper-facing coverage conclusion.
- Added full-catalog structured comparisons and premium summaries that distinguish total premium,
  subsidized premium, and subsidy.
- Added quote-availability handling and Medicare Supplement guidance for incomplete shopper inputs.
- Added document fallback for missing non-premium details while retaining independently supported
  facts. Premiums remain sourced from structured quote data.
- Strengthened plan selection, benefit attribution, conflicting-evidence handling, and preservation
  of coverage conditions.
- Added brand-aware general search, financial-assistance routing, English-only responses, and a
  Medicaid boundary that distinguishes questions from background context.
- Updated pre-invoke classification to direct WXO HTTP inference and response addenda to post-invoke
  delivery, preserving fallback exclusions.

## Compatibility

- Deploy the matching API/RAG contracts and re-import the tools, plugins, and agent; this is not a
  prompt-only update.
- Evaluated through the stage Shopper Assistant API revision
